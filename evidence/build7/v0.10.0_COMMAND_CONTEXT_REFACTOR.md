# VoiceStrike BUILD 7 v0.10.0 — Command Context Refactor

Operational command state is now explicit and command-scoped. Transcript text remains interpretation evidence, not a mutable source of truth. Typed slots drive tool arguments; workflow evidence and delayed tool ownership remain bound to the same commandId. Fact-level claim grounding prevents alternative inventory claims unless an authoritative completed read supports the exact location and quantity.

Preserved: E3 two-step protection, immutable turn authority, cancellation/stale-confirmation blocking, independent post-mutation verification, no blind mutation retry, ambient/TV rejection, orphan reply suppression, session epochs, Worker/Supervisor persistence, and transcript Copy/Export.
